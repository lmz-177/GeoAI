# GeoAI · 动态数学画板

单文件、零依赖、离线可用的网页版动态数学工具，界面与操作对标 GeoGebra 经典版。
直接用浏览器打开 `math.html` 即可使用，不需要构建、不需要安装、不加载任何外部脚本。

## 功能

- **五个面板**：代数区 / 绘图区 / CAS / 命令参考 / 表格
- **75 个作图工具**（与 GeoGebra 平面工具箱对齐）、200+ 命令行命令（含中文别名）
- **完整依赖关系**：拖动父对象，子对象实时联动；支持撤销 / 重做、图层、动画与轨迹
- **表达式引擎**：函数、圆锥曲线、隐式方程、变换、统计与概率分布
- **表格视图**：单元格公式与区间聚合，与画布双向引用
- **AI 助手**：自然语言作图与解题，支持看图识别、联网检索、思考强度可调
- **Markdown 排版**：对话与画布文本统一支持标题 / 列表 / 表格 / 任务清单 / 公式 / 代码块
- **对话导航**：右侧圆点按轮次跳转，长对话也能快速定位
- **离线优先**：仅 AI 与在线分享需要联网

## 使用

1. 下载 `math.html`，用浏览器打开。
2. 左侧面板输入表达式或命令，例如 `f(x) = x^2 - 2x - 3`、`Circle((0,0), 2)`。
3. 底部输入框用自然语言让 AI 作图或解题，例如「画出 y = sin(x) 和 y = cos(x)，标出交点」。

### 自测

- 核心功能：`math.html?selftest=1`
- 界面交互：`math.html?uitest=1`

## 说明

- AI 功能需要联网，并在 `math.html` 顶部的 `API_KEY` / `API_URL` / `MODEL` 处配置自己的服务。
- 除 AI 与在线分享外，其余功能全部离线运行。
